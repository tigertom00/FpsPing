# FpsPing

A small, movable box showing your FPS and latency (ms), built for **World of Warcraft: Forever** (interface `16001`). Values are color-coded green, yellow or red.

## Installation

Drop the `FpsPing` folder into:

```
World of Warcraft/_forever_/Interface/AddOns/
```

Then `/reload` or relaunch the client.

## Commands

| Command | Effect |
|---|---|
| `/fpsping` | Show the command list |
| `/fpsping lock` | Stop the box from being dragged |
| `/fpsping unlock` | Allow dragging again |
| `/fpsping reset` | Move the box back to its default position |
| `/fpsping show` | Show the box |
| `/fpsping hide` | Hide the box |
